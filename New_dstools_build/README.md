# Offline DStools SIF recipe

[English build guide](../docs/en/SIF_BUILD.md) · [中文构建说明](../docs/zh-CN/SIF_BUILD.md)

Use the accepted SIF for normal processing. This directory is only needed when
constructing a replacement. Upload the complete recipe, including `patches/`;
prepare network inputs on a login node, then build offline on Slurm.

日常处理使用已验收 SIF，仅在构建替代镜像时使用本目录。上传完整配方及
`patches/`，登录节点准备联网输入，再通过 Slurm 离线构建。
